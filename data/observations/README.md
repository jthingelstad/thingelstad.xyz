# Observations

Generated by `npm run collect`. Do not edit by hand.

`screenshot/` holds one JPEG per website thing next to its JSON. The JSON records the image's sha256, and the site publishes the image under `/assets/screenshots/` with the first ten hex digits of that hash in its name, so a new capture gets a new URL. Git history keeps the earlier captures. A thing with no live site to photograph (no `website` source of a thing that is not retired or abandoned) is photographed once from the first `archive` source its record marks `photograph: true`, whose url pins a 14-digit Wayback capture that someone has looked at: the collector loads it with `if_` (no toolbar), refuses a capture more than 30 days from the pin, on another host, or with none of its own stylesheets kept, and records the capture it was served under `wayback`. That picture is never taken again; a live screenshot always wins over it.

`commits/` holds one commit log per public repository and `publications/` one log of feed items per website with its own feed. Each is written one entry per line, so a new commit or post is a one-line diff, and Prettier leaves them alone (`.prettierignore`). A publication log only grows: an item that has aged out of its feed stays. Both feed `/activity/` and `activity.xml` (`collection/activity.ts`).

`validators/` holds one observation per thing whose record lists validators: block proposals by month and the validators' state, counts only (`collection/adapters/beacon.ts`). The first was read from Dora's slot lists; each run since counts on from `until`, the last finalized epoch counted.
