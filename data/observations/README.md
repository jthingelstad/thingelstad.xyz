# Observations

Generated by `npm run collect`. Do not edit by hand.

`screenshot/` holds one JPEG per website thing next to its JSON. The JSON records the image's sha256, and the site publishes the image under `/assets/screenshots/` with the first ten hex digits of that hash in its name, so a new capture gets a new URL. Git history keeps the earlier captures.

`commits/` holds one commit log per public repository and `publications/` one log of feed items per website with its own feed. Each is written one entry per line, so a new commit or post is a one-line diff, and Prettier leaves them alone (`.prettierignore`). A publication log only grows: an item that has aged out of its feed stays. Both feed `/activity/` and `activity.xml` (`collection/activity.ts`).
