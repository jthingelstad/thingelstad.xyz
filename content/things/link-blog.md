Link Thing was Jamie’s link blog at links.thingelstad.com. He already saved the links for the Weekly Thing to Pinboard with Markdown in their descriptions, and he realized the same Markdown could become Jekyll posts. Using the Pinboard API, he wrote each link out as a post and put an early version live, announced in [Weekly Thing 18](https://weekly.thingelstad.com/archive/18/) on September 9, 2017. It carried the same links as the newsletter, “but here it’s a full website with it’s own navigation and such.” In 2017 alone he saved [913 links](https://www.thingelstad.com/2018/01/20/in-links.html).

On November 8, 2020, Jamie [relaunched it](https://www.thingelstad.com/2020/11/08/i-got-my.html) to give the links he shared in the Weekly Thing “a permanent home on the web.” He added Commento comments as an experiment and Index pages listing every link saved from a given site. The last capture in the [Internet Archive](https://web.archive.org/web/20211207055926/https://links.thingelstad.com/), from December 2021, shows posts through December 2, 2021. The site is gone now.

In [Weekly Thing 274](https://weekly.thingelstad.com/archive/274/) in January 2024, Jamie wrote, “When I was running a link blog… I may create a link blog again in the future, but if I did I want it to not be blog-date-centric but instead content-keyword-search centric.” An earlier experiment with the same idea was links_thing, a [bookmarking wiki](https://www.thingelstad.com/2012/07/01/bookmarking-with-semantic.html) he built on Semantic MediaWiki in 2012 and filled with almost 4,000 links imported from Pinboard.
