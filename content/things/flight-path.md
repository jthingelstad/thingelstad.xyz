Flight Path lived at flightpath.poaprally.com: a rotating globe with every airport in the POAP Airport Rally, the number of claims at each, a leaderboard, and each collector’s own path. Jamie built it in one evening on an iPhone, from a CLAUDE.md written with ChatGPT and a cloud Claude Code session attached to a fresh repository, as told in Weekly Thing 342. The site read live POAP claims, and the host stopped answering after POAP wound down in 2026.
