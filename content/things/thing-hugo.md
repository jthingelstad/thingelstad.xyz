Thing Hugo is a theme for [Jamie’s blog](https://www.thingelstad.com/), which runs on Micro.blog. It installs as a Micro.blog plug-in on top of the Blank design and is built for Micro.blog’s Hugo 0.158. According to its [README](https://github.com/jthingelstad/thing-hugo/tree/v2), it marks up every post and page with IndieWeb microformats, uses a single narrow serif column set in Newsreader and Source Sans 3, and builds in Tinylytics, Pagefind search, an `/llms.txt` file, a strip linking Jamie’s other sites, and an “Explore with Thingy” link under each post.

The repository’s `main` branch holds the first version, a Hugo theme for Micro.blog with Pagefind, llms.txt, and Weekly Thing and Another Thing signup boxes. The `v2` branch is a rewrite from October 2026. As of October 2026 the live blog still uses Tiny Theme by Matt Langford.
