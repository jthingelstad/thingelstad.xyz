Ask Planet Kubb was a question-and-answer site for the Kubb community at ask.planetkubb.com. It welcomed visitors to a “community driven site to learn more about the great game of Kubb,” run alongside the Planet Kubb planet feed. It was online by June 2012, when Garrick van Buren and I linked it in [Open Loop #0](https://www.thingelstad.com/projects/open-loop/0-but-no-shoes/). A [July 2012 capture](https://web.archive.org/web/20120702124724/http://ask.planetkubb.com/) shows 75 questions, 182 answers and 64 users, with polls on who would win each group at the 2012 USA Kubb Nationals. Garrick and I built it together (“then we built Ask Planet Kubb”), and on [Open Loop #1](https://www.thingelstad.com/projects/open-loop/1-big-fuzzy-dead-cat/) I called it “the number one place for Q&A in the community,” adding, “it’s a low bar.” Garrick was one of its most active answerers.

I ran the site on [Question2Answer](https://www.question2answer.org/) “for a number of years,” liking it because it was simple to run on PHP and MySQL. Spam registrations kept getting through ReCaptcha and a text-question captcha, so in November 2014 I wrote [q2a-number-captcha](https://github.com/jthingelstad/q2a-number-captcha), which asks for one digit of a nine-digit number spelled out in words ([Question2Answer Number Captcha](https://www.thingelstad.com/2014/11/16/questionanswer-number-captcha.html)).

The Wayback Machine shows the site still serving questions in [July 2018](https://web.archive.org/web/20180720082755/http://ask.planetkubb.com/), with the last answers dated December 2017. By [November 2018](https://web.archive.org/web/20181108010540/http://ask.planetkubb.com/) the address showed only a default web server page.
